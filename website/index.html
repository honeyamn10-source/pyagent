from pyagent import Agent, tool, Memory, RetryPolicy from pyagent.llm import MockLLM @tool def search_docs(query: str) -> list[dict]: \"\"\"Search documentation.\"\"\" return [{\"title\": \"API Reference\", \"url\": \"...\"}] @tool def run_code(code: str) -> str: \"\"\"Execute Python safely.\"\"\" return exec_sandboxed(code) llm = MockLLM(responses=[ \"I'll search the docs for you.\", \"Here's the example you need.\" ]) memory = Memory() agent = Agent( llm=llm, tools=[search_docs, run_code], memory=memory, retry=RetryPolicy(max_attempts=3), ) result = agent.run( \"Find the API reference for authentication and show me an example.\" ) print(result.final_answer)

Core Primitives

Five building blocks. Compose them your way.

BaseLLM

Abstract interface. Implement generate(messages, tools). Includes MockLLM, OpenAICompatible, Ollama adapters.

@tool Decorator

Turn any function into a tool. Auto schema from type hints + docstring. Async & sync support.

Agent

Orchestrates: LLM → tools → results → LLM. Max steps, streaming, callbacks, error handling.

Memory

Conversation history + auto-summarization. In-memory, SQLite, custom backends.

RetryPolicy

Exponential backoff, jitter, configurable exceptions. Applies to LLM + tools.

Hooks

Lifecycle: on_llm_start/end, on_tool_start/end, on_error. Async supported.

Tool System

Type hints + docstring = full OpenAPI schema. Zero boilerplate.

Memory System

Conversation history with auto-summarization. Pluggable backends.

In-Memory

Default. Fast, ephemeral. Memory()

SQLite

Persistent. SQLiteMemory("agent.db"). Search, export, multi-session.

Summarization

Auto-summarizes when token budget exceeded. Configurable threshold + model.

Custom Backend

Implement MemoryBackend protocol. Redis, Postgres, vector stores.

Examples

Code Assistant

@tool
def read_file(path: str) -> str: ...
@tool
def write_file(path: str, content: str) -> str: ...
@tool
def run_tests() -> dict: ...

agent = Agent(llm, tools=[read_file, write_file, run_code])

Research Agent

@tool
def search(query: str) -> list: ...
@tool
def fetch(url: str) -> str: ...

agent = Agent(llm, tools=[search, fetch], memory=SQLiteMemory("research.db"))

Data Analyst

@tool
def query(sql: str) -> list[dict]: ...
@tool
def plot(data: list, kind: str) -> bytes: ...

agent = Agent(llm, tools=[query, plot], memory=Memory())
