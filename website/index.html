04 / Know the scope

Clear expectations.

Model quality and costs depend on the provider. Tools run with the permissions you give their Python process; this library is not an operating-system sandbox.

Check the latest results in GitHub Actions. A passing automated check covers its tested paths, not every real-world integration.
